# 📖 理解 ModelGo

## 如何構建

**ModelGo 授權條款 V2** 是 V1 的完全重寫版本，由 [段默明](https://scholar.google.com/citations?user=vEWocfwAAAAJ) 博士與 **NUS IDS** 和新加坡法律專家共同創建，靈感來自 **OpenRAILs** 和 **Creative Commons**。V2 解決了 V1 潛在的版權問題（因為 V1 是現有授權條款的混合版本）。我們將其貢獻給公眾。請放心使用 ModelGo V2。

## 結構

ModelGo 授權條款由六個章節組成。第 2 節「授權權利」是授予權利許可並聲明使用和分發限制的 <mark style="color:purple;">核心條款</mark>。

ModelGo 授權條款包含免責聲明和責任限制（第 3、4 節）。此外，我們的授權條款在第 6 節中包含條款，允許您修改授權條款文本，前提是您提供描述您對此授權條款所做修改的可讀通知。
