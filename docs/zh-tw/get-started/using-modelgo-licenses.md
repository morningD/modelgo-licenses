# 🚀 使用 ModelGo 授權條款

ModelGo 授權條款包含八種變體，分為**寬鬆授權**、**有條件寬鬆授權**和**嚴格授權**三類。請選擇最適合您需求的授權條款。

### 寬鬆授權

這些授權條款可再授權且不可撤銷，對衍生品<mark style="color:purple;">幾乎沒有限制</mark>。

:::tabs
== MG0

| 授權條款全稱 | ModelGo Zero License 2.0 |
|---|---|
| 簡短標識符 | MG0-2.0 |
| 標籤 | 寬鬆、可再授權、不可撤銷 |
| 用途 | 以幾乎無限制的方式發布模型，僅保留關於擔保、責任和終止的條款。接收者可以移除您的署名和授權文件。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

### 有條件寬鬆授權

這些授權條款包含一些<mark style="color:purple;">著作權保護（Copyleft）風格的條款</mark>。接收者可以自由使用和製作衍生品，前提是遵守原始作品中指定的有條件授權條款。

:::tabs
== MG-BY-SA

| 授權條款全稱 | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| 簡短標識符 | MG-BY-SA-2.0 |
| 標籤 | 著作權保護、公開原始碼、不可再授權、不可撤銷 |
| 用途 | 發布模型並要求對所有副本及後續衍生品開源模型權重、架構、訓練和測試程式碼/腳本等（不包括數據和系統函式庫）。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

### 嚴格授權

這些授權條款為<mark style="color:purple;">非自由</mark>授權，包含<mark style="color:purple;">嚴格的再分發限制</mark>，例如僅限非商業用途和/或禁止共享原始作品的衍生品。它們還要求在將模型輸出作為數據集發布時標註模型出處。

:::tabs
== MG-BY-NC

| 授權條款全稱 | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| 簡短標識符 | MG-BY-NC-2.0 |
| 標籤 | 禁止商業使用、不可再授權、與 GPL 不相容、<mark style="color:purple;">**可撤銷**</mark> |
| 用途 | 發布模型並禁止商業使用，即不允許對原始模型及其衍生品以及配套程式碼和腳本進行任何商業使用（包括 SaaS）。請注意，此授權條款的授權可以被撤銷。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |

## 如何將 ModelGo 授權條款應用到您的模型

  </div>

  </div>
</div>
