# 🚀 Использование лицензий ModelGo

Лицензии ModelGo включают восемь вариантов, сгруппированных в **Разрешительные лицензии**, **Условно-разрешительные лицензии** и **Строгие лицензии**. Пожалуйста, выберите вариант, наиболее соответствующий вашим потребностям.

### Разрешительные лицензии

Эти лицензии допускают сублицензирование и являются безотзывными, с <mark style="color:purple;">практически полным отсутствием ограничений</mark>, применяемых к производным работам.

:::tabs
== MG0

| Полное название лицензии | ModelGo Zero License 2.0 |
|---|---|
| Краткий идентификатор | MG0-2.0 |
| Теги | Разрешительная, Сублицензируемая, Безотзывная |
| Назначение | Публикация моделей практически без ограничений, за исключением условий, касающихся гарантий, ответственности и прекращения действия. Получатели могут удалить указание авторства и файл лицензии. |
| Полный текст | [Просмотр на GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

### Условно-разрешительные лицензии

Эти лицензии включают некоторые <mark style="color:purple;">условия в стиле копилефт</mark>. Получатели могут свободно использовать и создавать производные работы при условии соблюдения указанных условных лицензионных требований оригинальной работы.

:::tabs
== MG-BY-SA

| Полное название лицензии | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| Краткий идентификатор | MG-BY-SA-2.0 |
| Теги | Копилефт, Раскрытие исходного кода, Несублицензируемая, Безотзывная |
| Назначение | Публикация моделей с требованием открыть исходный код весов модели, архитектур, кода/скриптов обучения и тестирования и т.д. (за исключением данных и системных библиотек) для всех копий и последующих производных работ. |
| Полный текст | [Просмотр на GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

### Строгие лицензии

Эти лицензии являются <mark style="color:purple;">несвободными</mark> и содержат <mark style="color:purple;">строгие ограничения на распространение</mark>, такие как использование только в некоммерческих целях и/или запрет на распространение производных работ оригинального произведения. Они также требуют указания авторства модели при публикации выходных данных модели в качестве наборов данных.

:::tabs
== MG-BY-NC

| Полное название лицензии | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| Краткий идентификатор | MG-BY-NC-2.0 |
| Теги | Запрет коммерческого использования, Несублицензируемая, Несовместима с GPL, <mark style="color:purple;">**Отзываемая**</mark> |
| Назначение | Публикация моделей с запретом на коммерческое использование означает, что любое коммерческое использование (включая SaaS) оригинальных моделей и их производных, а также сопутствующего кода и скриптов, не допускается. Обратите внимание, что предоставленные права по этой лицензии могут быть отозваны. |
| Полный текст | [Просмотр на GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |
