# 🚀 使用 ModelGo 许可证

ModelGo 许可证包含八种变体，分为**宽松许可证**、**有条件宽松许可证**和**严格许可证**。请选择最适合您需求的许可证。

### 宽松许可证

这些许可证是可再许可和不可撤销的，对衍生品 <mark style="color:purple;">几乎没有限制</mark>。

:::tabs
== MG0

| 许可证全称 | ModelGo Zero License 2.0 |
|---|---|
| 简短标识符 | MG0-2.0 |
| 标签 | 宽松、可再许可、不可撤销 |
| 用途 | 以几乎没有限制的方式发布模型，除了关于保证、责任和终止的条款。接收者可以移除您的署名和许可证文件。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

<details>
<summary>将 👇 添加到您的 README</summary>

```
### Model License:

This model is licensed under the ModelGo Zero License, Version 2.0 (MG0-2.0);
you may use this model only in compliance with the License.
You may obtain a copy of the License at

https://ids.nus.edu.sg/docs/modelgo/v2/MG0/LICENSE
```

</details>

== MG-BY

| 许可证全称 | ModelGo Attribution License 2.0 |
|---|---|
| 简短标识符 | MG-BY-2.0 |
| 标签 | 宽松、可再许可、不可撤销 |
| 用途 | 在 MG0 的基础上，接收者应保留原始作品中的所有署名信息和其他声明在其副本和衍生品中，还需要提供修改声明。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY/LICENSE) |

<details>
<summary>将 👇 添加到您的 README</summary>

```

```

</details>

### 有条件宽松许可证

这些许可证包含一些 <mark style="color:purple;">Copyleft 风格的条款</mark>。接收者可以自由使用和创建衍生品，只要他们遵守原始作品指定的许可条款。

:::tabs
== MG-BY-SA

| 许可证全称 | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| 简短标识符 | MG-BY-SA-2.0 |
| 标签 | Copyleft、公开源代码、不可再许可、不可撤销 |
| 用途 | 发布模型，要求所有副本和后续衍生品开源模型权重、架构、训练和测试代码/脚本等（不包括数据和系统库）。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

<details>
<summary>将 👇 添加到您的 README</summary>

```

you may use this model only in compliance with the License.
You may obtain a copy of the License at

https://ids.nus.edu.sg/docs/modelgo/v2/MG-BY-SA/LICENSE
```

</details>

== MG-BY-RAI

| 许可证全称 | ModelGo Attribution-ResponsibleAI License 2.0 |
|---|---|
| 简短标识符 | MG-BY-RAI-2.0 |
| 标签 | 弱 Copyleft、负责任 AI、不可再许可、<mark style="color:purple;">**可撤销**</mark>、与 GPL 不兼容 |
| 用途 | 发布模型，附带负责任使用 AI 的条款，这是 [RAIL](https://www.licenses.ai) 所倡导的。请注意，通过应用此许可证，所有副本和后续衍生品将受到这些基于使用的限制条款的约束。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-RAI/LICENSE) |

### 严格许可证

这些许可证是 <mark style="color:purple;">非自由的</mark>，包含 <mark style="color:purple;">严格的再分发限制</mark>，例如仅限非商业用途和/或禁止共享原始作品的衍生品。它们还要求在将模型输出发布为数据集时注明模型出处。

:::tabs
== MG-BY-NC

| 许可证全称 | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| 简短标识符 | MG-BY-NC-2.0 |
| 标签 | 禁止商业使用、不可再许可、与 GPL 不兼容、<mark style="color:purple;">**可撤销**</mark> |
| 用途 | 发布模型，禁止商业使用意味着不允许对原始模型及其衍生品以及配套代码和脚本进行任何形式的商业使用（包括 SaaS）。请注意，此许可证授予的权利可以被撤销。 |
| 完整文本 | [在 GitHub 上查看 →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |
