# 📖 理解 ModelGo

## 如何构建

**ModelGo 许可证 V2** 是 V1 的完全重写版本，由 [段默明](https://scholar.google.com/citations?user=vEWocfwAAAAJ) 博士与 **NUS IDS** 和新加坡法律专家共同创建，灵感来自 **OpenRAILs** 和 **Creative Commons**。V2 解决了 V1 潜在的版权问题（因为 V1 是现有许可证的混合版本）。我们将其贡献给公众。请放心使用 ModelGo V2。

## 结构

ModelGo 许可证由六个章节组成。第 2 节"许可权利"是授予权利许可并声明使用和分发限制的 <mark style="color:purple;">核心条款</mark>。

ModelGo 许可证包含免责声明和责任限制（第 3、4 节）。此外，我们的许可证在第 6 节中包含条款，允许您修改许可证文本，前提是您提供描述您对此许可证所做修改的可读通知。
