# 📖 ModelGoを理解する

## 構築の経緯

**ModelGo Licenses V2**は、V1の完全な改訂版であり、Dr. [Moming Duan](https://scholar.google.com/citations?user=vEWocfwAAAAJ)が**NUS IDS**およびシンガポールの法律専門家と協力して作成しました。**OpenRAILs**および**Creative Commons**に着想を得ています。V2はV1の潜在的な著作権問題（V1が既存のライセンスのリミックスであったことに起因）を解決しています。私たちはこれをパブリックに捧げます。安心してModelGo V2をご使用ください。

## 構造

ModelGoライセンスは6つのセクションで構成されています。セクション2「License Rights」は、権利ライセンスを付与し、使用と配布の制限を規定する<mark style="color:purple;">主要な条項</mark>です。

ModelGoライセンスには、免責事項および責任制限（セクション3、4）が含まれています。さらに、セクション6に記載されているように、ライセンステキストの変更を許可する条項が含まれており、その場合は変更内容を読みやすく記載した通知を提供する必要があります。
