# 🚀 ModelGoライセンスの使い方

ModelGoライセンスには8つのバリエーションがあり、**寛容なライセンス**、**条件付き寛容ライセンス**、**厳格なライセンス**の3つに分類されます。あなたのニーズに最も適したものをお選びください。

### 寛容なライセンス

これらのライセンスはサブライセンス可能かつ撤回不可能であり、派生物に対する制限が<mark style="color:purple;">ほとんどありません</mark>。

:::tabs
== MG0

| ライセンス正式名称 | ModelGo Zero License 2.0 |
|---|---|
| 短縮識別子 | MG0-2.0 |
| タグ | 寛容、サブライセンス可能、撤回不可能 |
| 用途 | 保証、責任、終了に関する条項を除き、ほとんど制限なしにモデルを公開します。受領者はあなたの帰属表示とライセンスファイルを削除することができます。 |
| 全文 | [GitHubで見る →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

</details>

| 全文 | [GitHubで見る →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY/LICENSE) |

### 条件付き寛容ライセンス

これらのライセンスには<mark style="color:purple;">コピーレフトスタイルの条項</mark>が含まれています。受領者は、元の著作物の指定された条件付きライセンス条項に準拠する限り、自由に使用および派生物を作成できます。

:::tabs
== MG-BY-SA

| ライセンス正式名称 | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| 短縮識別子 | MG-BY-SA-2.0 |
| タグ | コピーレフト、ソース開示、サブライセンス不可、撤回不可能 |
| 用途 | すべてのコピーおよびその後の派生物に対して、モデルの重み、アーキテクチャ、トレーニングおよびテストのコード/スクリプトなど（データとシステムライブラリを除く）をオープンソース化する要件付きでモデルを公開します。 |
| 全文 | [GitHubで見る →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

### 厳格なライセンス

これらのライセンスは<mark style="color:purple;">非フリー</mark>であり、非商用目的のみの使用や元の著作物の派生物の共有禁止など、<mark style="color:purple;">厳格な再配布制限</mark>が含まれています。また、モデル出力をデータセットとして公開する際にモデルの帰属表示が必要です。

:::tabs
== MG-BY-NC

| ライセンス正式名称 | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| 短縮識別子 | MG-BY-NC-2.0 |
| タグ | 商用利用禁止、サブライセンス不可、GPL非互換、<mark style="color:purple;">**撤回可能**</mark> |
| 用途 | 商用利用禁止の条件付きでモデルを公開します。元のモデルとその派生物、および補完的なコードとスクリプトに対するいかなる商用利用（SaaSを含む）も許可されません。このライセンスの権利付与は撤回可能であることにご注意ください。 |
| 全文 | [GitHubで見る →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |

## ModelGoライセンスをあなたのモデルに適用する方法

<div class="step-card">
  <div class="step-number">1</div>
  <div class="step-body">
    <h4>MGライセンスファイルを追加</h4>
    <p>上記のリンクから<strong>LICENSE</strong>ファイルをダウンロードし、Hugging Faceプロジェクトのディレクトリに配置してください。</p>

<div class="step-card">
  <div class="step-number">2</div>

    <h4>MGライセンスを宣言</h4>

  </div>
</div>
<div class="step-card">
  <div class="step-number">3</div>
  <div class="step-body">
    <h4>Model Sheetを使用 <span class="step-optional">任意</span></h4>

  </div>
</div>
</div>
