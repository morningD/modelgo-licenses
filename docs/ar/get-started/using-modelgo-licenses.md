# 🚀 استخدام تراخيص ModelGo

تتضمن تراخيص ModelGo ثمانية متغيرات، مقسمة إلى **تراخيص متساهلة**، و**تراخيص متساهلة مشروطة**، و**تراخيص صارمة**. يرجى اختيار الترخيص الأنسب لاحتياجاتك.
