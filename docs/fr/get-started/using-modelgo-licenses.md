# 🚀 Utiliser les licences ModelGo

Les licences ModelGo comprennent huit variantes, regroupées en **Licences permissives**, **Licences conditionnellement permissives** et **Licences strictes**. Veuillez sélectionner celle qui correspond le mieux à vos besoins.

### Permissives

Ces licences sont sous-licenciables et irrévocables, avec <mark style="color:purple;">quasiment aucune restriction</mark> appliquée aux dérivés.

:::tabs
== MG0

| Nom complet de la licence | ModelGo Zero License 2.0 |
|---|---|
| Identifiant court | MG0-2.0 |
| Tags | Permissive, Sous-licenciable, Irrévocable |
| Objectif | Publier des modèles avec quasiment aucune restriction, à l'exception des clauses relatives à la Garantie, la Responsabilité et la Résiliation. Les destinataires peuvent retirer votre attribution et votre fichier de licence. |
| Texte complet | [Voir sur GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

<details>
<summary>Add 👇 to your README</summary>

```
### Model License:

This model is licensed under the ModelGo Zero License, Version 2.0 (MG0-2.0);
you may use this model only in compliance with the License.
You may obtain a copy of the License at

https://ids.nus.edu.sg/docs/modelgo/v2/MG0/LICENSE
```

</details>

|---|---|
| Identifiant court | MG-BY-2.0 |
| Tags | Permissive, Sous-licenciable, Irrévocable |

| Texte complet | [Voir sur GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY/LICENSE) |

### Conditionnellement permissives

Ces licences incluent certaines <mark style="color:purple;">clauses de type copyleft</mark>. Les destinataires peuvent librement utiliser et créer des dérivés tant qu'ils respectent les conditions de licence spécifiées de l'œuvre originale.

:::tabs
== MG-BY-SA

| Nom complet de la licence | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| Identifiant court | MG-BY-SA-2.0 |
| Tags | Copyleft, Divulgation du code source, Non sous-licenciable, Irrévocable |
| Objectif | Publier des modèles avec l'obligation de rendre open source les poids du modèle, les architectures, le code et les scripts d'entraînement et de test, etc. (à l'exclusion des données et des bibliothèques système) pour toutes les copies et dérivés ultérieurs. |
| Texte complet | [Voir sur GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

### Strictes

Ces licences sont <mark style="color:purple;">non libres</mark> et contiennent des <mark style="color:purple;">restrictions strictes de redistribution</mark>, telles que l'utilisation à des fins non commerciales uniquement et/ou l'interdiction de partager les dérivés de l'œuvre originale. Elles exigent également l'attribution du modèle lors de la publication des sorties du modèle sous forme de jeux de données.

:::tabs
== MG-BY-NC

| Nom complet de la licence | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| Identifiant court | MG-BY-NC-2.0 |
| Tags | Pas d'utilisation commerciale, Non sous-licenciable, Incompatible GPL, <mark style="color:purple;">**Révocable**</mark> |
| Objectif | Publier des modèles avec une interdiction commerciale signifiant que toute utilisation commerciale (y compris le SaaS) des modèles originaux et de leurs dérivés, ainsi que du code et des scripts complémentaires, n'est pas autorisée. Veuillez noter que les droits accordés par cette licence peuvent être révoqués. |
| Texte complet | [Voir sur GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |
