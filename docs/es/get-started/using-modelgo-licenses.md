# 🚀 Uso de las licencias ModelGo

Las licencias ModelGo incluyen ocho variantes, agrupadas en **Licencias permisivas**, **Licencias condicionalmente permisivas** y **Licencias estrictas**. Por favor, seleccione la que mejor se adapte a sus necesidades.

### Permisivas

Estas licencias son sublicenciables e irrevocables, con <mark style="color:purple;">casi ninguna restriccion</mark> aplicada a los derivados.

:::tabs
== MG0

| Nombre completo de la licencia | ModelGo Zero License 2.0 |
|---|---|
| Identificador corto | MG0-2.0 |
| Etiquetas | Permisiva, Sublicenciable, Irrevocable |
| Proposito | Publicar modelos con casi ninguna restriccion excepto los terminos relativos a Garantia, Responsabilidad y Terminacion. Los destinatarios pueden eliminar su atribucion y archivo de licencia. |
| Texto completo | [View on GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG0/LICENSE) |

<details>
<summary>Add 👇 to your README</summary>

```
### Model License:

This model is licensed under the ModelGo Zero License, Version 2.0 (MG0-2.0);
you may use this model only in compliance with the License.
You may obtain a copy of the License at

https://ids.nus.edu.sg/docs/modelgo/v2/MG0/LICENSE
```

</details>

== MG-BY

| Nombre completo de la licencia | ModelGo Attribution License 2.0 |
|---|---|
| Identificador corto | MG-BY-2.0 |
| Etiquetas | Permisiva, Sublicenciable, Irrevocable |
| Proposito | Ademas de las disposiciones de MG0, los destinatarios deben conservar toda la informacion de atribucion y otros avisos de la obra original en sus copias y derivados, y tambien se requiere una declaracion de modificaciones. |
| Texto completo | [View on GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY/LICENSE) |

<details>
<summary>Add 👇 to your README</summary>

you may use this model only in compliance with the License.

</details>

:::

### Condicionalmente permisivas

Estas licencias incluyen algunos <mark style="color:purple;">terminos de estilo copyleft</mark>. Los destinatarios pueden usar libremente y crear derivados siempre que cumplan con los terminos condicionales especificados de la licencia de la obra original.

:::tabs
== MG-BY-SA

| Nombre completo de la licencia | ModelGo Attribution-ShareAlike License 2.0 |
|---|---|
| Identificador corto | MG-BY-SA-2.0 |
| Etiquetas | Copyleft, Divulgacion de codigo fuente, No sublicenciable, Irrevocable |
| Proposito | Publicar modelos con el requisito de hacer codigo abierto los pesos del modelo, arquitecturas, codigo/scripts de entrenamiento y prueba, etc. (excluyendo datos y bibliotecas del sistema) para todas las copias y derivados subsiguientes. |
| Texto completo | [View on GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-SA/LICENSE) |

<summary>Add 👇 to your README</summary>

### Estrictas

Estas licencias son <mark style="color:purple;">no libres</mark> y contienen <mark style="color:purple;">restricciones estrictas de redistribucion</mark>, como solo para fines no comerciales y/o prohibir el intercambio de derivados de la obra original. Tambien requieren la atribucion del modelo al publicar las salidas del modelo como conjuntos de datos.

:::tabs
== MG-BY-NC

| Nombre completo de la licencia | ModelGo Attribution-NonCommercial License 2.0 |
|---|---|
| Identificador corto | MG-BY-NC-2.0 |
| Etiquetas | Sin uso comercial, No sublicenciable, Incompatible con GPL, <mark style="color:purple;">**Revocable**</mark> |
| Proposito | Publicar modelos con la prohibicion de uso comercial, lo que significa que cualquier tipo de uso comercial (incluyendo SaaS) de los modelos originales y sus derivados, asi como el codigo y scripts complementarios, no esta permitido. Tenga en cuenta que los derechos otorgados por esta licencia pueden ser revocados. |
| Texto completo | [View on GitHub →](https://github.com/Xtra-Computing/ModelGo/blob/main/MGL/V2/MG-BY-NC/LICENSE) |

## Como aplicar las licencias ModelGo a su modelo

<div class="step-card">
  <div class="step-number">1</div>
  <div class="step-body">
    <h4>Agregar el archivo de licencia MG</h4>
    <p>Descargue el archivo <strong>LICENSE</strong> desde el enlace anterior y coloquelo en el directorio de su proyecto de Hugging Face.</p>
  </div>
</div>

  <div class="step-number">2</div>
  <div class="step-body">
    <h4>Declarar la licencia MG</h4>

  </div>
</div>
<div class="step-card">
  <div class="step-number">3</div>
  <div class="step-body">

  </div>
</div>
</div>
